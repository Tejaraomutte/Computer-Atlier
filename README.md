# Computer Architecture Atelier

## Stack
- React
- Vite
- React Router
- Three.js
- React Three Fiber
- @react-three/drei
- Lucide React

## Run

```bash
npm install
npm run dev
```

The viewer supports:
- mouse drag = rotate
- mouse wheel = zoom
- click a block = select it
- Isolate = fade other components
- Layers = show/hide architecture layers
- Data Flow = animate a particle through the datapath
- Reset = return the camera

## 3D models

The `.glb` files included here are simple placeholder geometry so the asset paths exist.
For a polished academic product, replace them with detailed CPU, ALU, register, cache,
RAM, ROM and complete-system GLB models created in Blender or another 3D tool.

The current viewer is intentionally procedural, so it works even without loading the GLB files.
